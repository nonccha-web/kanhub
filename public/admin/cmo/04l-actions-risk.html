Risk + Mitigation

RiskโอกาสเกิดMitigation
ผู้ค้าภาคใต้มอง "KAN ขายแข่ง" ไม่ยอมซื้อสูงFAQ ตอบตรงทุกช่องทาง + นโยบายไม่เปิดปลีกออนไลน์ + พิสูจน์ด้วย lot แยก ตะเข็บเดิม
เพจปลอม KAN HUB โผล่มาโกงลูกค้าสูง (ทั้งวงการโดน)ประกาศ "บัญชีบริษัทเท่านั้น" ทุกโพสต์ทุกไลฟ์ + ขอ verified badge + เก็บหลักฐานแจ้งความเร็ว
Live ครั้งแรกคนดูน้อย ทีมเสียกำลังใจกลาง-สูงตั้ง expectation: 3 events แรกคือการเรียน ไม่ใช่ยอด · วัด trend ไม่วัดครั้งเดียว · hype cycle เต็มทุกครั้ง
สต๊อกขายส่งชนกับความต้องการ retailกลางแยก lot ตั้งแต่สั่งนำเข้า + คุณออน confirm สัดส่วนชัดก่อนเริ่ม
คู่แข่งกรุงเทพอัดโปรแรงกว่า (สงครามราคา)กลางไม่ตามลดต่ำกว่า floor — สู้ด้วยค่าส่งถูกกว่า + มาดูของได้ + เปิดกระสอบถ่ายรูปก่อนส่ง
ทีมไม่พอ run 2 channel + retail พร้อมกันกลางPilot ความถี่ต่ำ (live 2/เดือน · โพสต์ 1/วัน) + รีบปิด 3 JD + ตัด channel ที่แพ้ตั้งแต่ ก.ย.
เปิดกระสอบสดแล้วเจอ lot คุณภาพต่ำกลางไลฟ์ต่ำ-กลางQC กระสอบที่จะเปิดก่อนไลฟ์ (เปิดดูตะเข็บข้าง ไม่แกะ) + ถ้าเจอจริง พูดตรงๆ ในไลฟ์ = trust เพิ่มไม่ใช่ลด
