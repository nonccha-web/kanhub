4 เสา Content

เสาสัดส่วนตัวอย่างโพสต์เป้า
1. ของจริง-ราคาจริง40%รูปกระสอบ + รหัส + ราคาตั้ง/โปร + จำนวนตัวโดยประมาณ (format นิ่งแบบ Sabuyorder)แม่ค้าเช็คราคา-สั่งได้เลย
2. เปิดกระสอบโชว์25%คลิปสั้นเปิดกระสอบ นับของ โชว์สภาพ (ตัด highlight จากไลฟ์)พิสูจน์ของจริง — แก้ pain "กลัวเจอขยะ"
3. แม่ค้าทำเงิน20%"กระสอบนี้ 45 โล ~200 ตัว ขายตัวละ 59 = ยอด 11,800 ต้นทุน 4,500" · รีวิวลูกค้า · ลูกค้ามารับของที่โกดังสอน unit economics (ต้นทุน-กำไรต่อหน่วย) >> เชื่อว่าซื้อแล้วรอด
4. หลังบ้านนำเข้า15%ตู้เข้าท่าเรือ · เปิดตู้ · กองในโกดัง · ทีมแพ็คTrust — ยืนยันนำเข้าจริง โกดังจริง กันมิจฉาชีพแอบอ้าง

ความถี่

  • Pilot: 1 โพสต์/วัน ทุกวัน — สลับเสาตามสัดส่วน
  • สัปดาห์ที่มีไลฟ์ ใช้ hype cycle (D-7 / D-3 / D-1 / D-Day / D+1) แทนโพสต์ปกติ
  • เทียบ: Update Station โพสต์วันละหลายโพสต์ (มี live ทุกวันป้อน content) — KAN เริ่มจากความสม่ำเสมอก่อน
