หัวข้อ 1 · ทีมการตลาด 2026

Job Description รายตำแหน่ง

หน้าที่ความรับผิดชอบ + เป้าใหญ่ (Objective) ของ 4 ตำแหน่ง · ดู KPI ที่เมนูย่อย KPI รายตำแหน่ง
1 · Marketing Manager
คุมภาพรวมทั้ง B2B และ B2C + ดูแลค้าปลีก/หน้าร้านเอง (รวมงาน B2C Manager เดิม) · ขึ้นตรง CMO
หน้าที่ความรับผิดชอบ
  • วางแผนการตลาดรวมทั้งสายค้าส่งและค้าปลีกให้สอดคล้องกับเป้าธุรกิจ
  • ดึงคนเข้าร้านทุกสาขาผ่านแคมเปญ/กิจกรรมหน้าร้าน และเพิ่มสัดส่วนคนที่ซื้อจริง (conversion) ร่วมกับฝ่าย Sale
  • คุมการสื่อสารแบรนด์และอัตลักษณ์ทุกช่องทางให้เป็นแนวเดียวกัน + ดูแลประสบการณ์/การจัดหน้าร้าน
  • ออกแบบและสร้างฐานลูกค้าสมาชิกทั้ง B2B และ B2C · ประสานฝ่ายผลิต/สต๊อกเรื่องจัดสรรสินค้าระหว่างคลังค้าส่งกับหน้าร้าน
  • คุมและจัดสรรงานของ B2B Manager และ Marketing Officer · ดูแลปฏิทินแคมเปญทั้งปี ตั้งเป้าทีมรายเดือนและปรับแผนเมื่อยอดไม่เข้าเป้า
Objectiveทำให้ค้าส่งและค้าปลีกโตไปด้วยกัน ของหมุนเร็วไม่ค้างสต๊อก · ดึงคนเข้าร้านมากขึ้นและเปลี่ยนเป็นลูกค้าจริงในสัดส่วนที่สูงขึ้น
2 · B2B Manager
คุมสายค้าส่ง + ไลฟ์ · ขึ้นตรง Marketing Manager
หน้าที่ความรับผิดชอบ
  • วางแผนและคุมยอดขายค้าส่ง B2B ทุกช่องทาง (ไลฟ์ + ค้าส่งตรง) ให้เป็นไปตามเป้า
  • กำหนดกลยุทธ์ราคา/โปรค้าส่ง และปิดดีลรายใหญ่ ยกตู้/ยกกระสอบ
  • ดูแลความสัมพันธ์ลูกค้าค้าส่งรายใหญ่ให้กลับมาซื้อซ้ำ
  • คุม มอบหมายงาน และพัฒนา B2B Executive · ประสานฝ่ายคลัง/สต๊อกให้ของพร้อมขายส่งและไลฟ์
  • เก็บและวิเคราะห์ข้อมูลลูกค้าค้าส่ง ส่งต่อให้ Marketing Manager
Objectiveสร้างยอดค้าส่งให้โตและคาดการณ์ได้ คุมทีม B2B และรักษาลูกค้าให้ซื้อซ้ำ
3 · B2B Executive
ลงมือขายค้าส่ง + ไลฟ์ · ขึ้นตรง B2B Manager
หน้าที่ความรับผิดชอบ
  • รับลูกค้าค้าส่งที่ทักเข้ามา ตอบ และปิดการขายให้จบ
  • ดำเนินการไลฟ์ขายตามรอบที่ B2B Manager วางไว้ (host / ผู้ช่วย)
  • ติดตามลูกค้าเดิมให้กลับมาซื้อซ้ำ
  • จัดเตรียมของ/คิวไลฟ์ ร่วมกับฝ่ายคลัง
  • บันทึกข้อมูลลูกค้าค้าส่งเข้าระบบให้ครบถ้วน
Objectiveปิดการขายค้าส่งและทำไลฟ์ให้ได้ยอดตามเป้าที่ B2B Manager วางไว้ พร้อมพัฒนาตัวเองสู่ระดับ Manager
4 · Marketing Officer
ผลิตคอนเทนต์ สื่อ ดูแลลูกค้า · ขึ้นตรง Marketing Manager
หน้าที่ความรับผิดชอบ
  • ผลิตคอนเทนต์ลงทุกช่องทางอย่างสม่ำเสมอ ทั้งภาพ วิดีโอสั้น คลิปเล่าเรื่องสินค้า
  • คุมโทนภาพและการเล่าเรื่องของแบรนด์ให้เป็นแนวเดียวกัน
  • วางคอนเทนต์ให้สอดรับปฏิทินแคมเปญและโปรโมชั่น
  • ดูแลและตอบลูกค้าทุกช่องทาง
  • เพิ่มใหม่ ดูแลงานจัดแสดงหน้าร้าน window display ป้ายโปรโมชั่น และการตกแต่งร้าน
Objectiveผลิตสื่อและดูแลลูกค้าให้คอนเทนต์ดึงคนเข้าร้านและปิดการขายได้
