โครงสร้างปรับใหม่: รวมงาน B2C Manager เข้ากับ Marketing Manager (MM คุมภาพรวม + ค้าปลีก/หน้าร้านเอง) · เพิ่มสาย B2B เป็น B2B Manager + B2B Executive · ตัวเลขเป้าบางส่วนยังรอค่าฐานจริงจากหลังบ้าน/POS · JD เป็นฉบับร่าง ควรปรับให้ตรงงานจริง

ผังทีมการตลาด

CMO → Marketing Manager → B2B Manager → B2B Executive · Marketing Officer
CMO
คุณ (หัวทีม) · คุม strategy + งบ
Marketing Manager
คุมภาพรวมทั้ง B2B และ B2C + ดูแลค้าปลีก/หน้าร้านเอง
B2B Manager
คุมสายค้าส่ง + ไลฟ์
B2B Executive
ลงมือขายค้าส่ง + ไลฟ์
Marketing Officer
คอนเทนต์ · สื่อ · จัดหน้าร้าน · ดูแลลูกค้า
B2B Manager และ Marketing Officer ขึ้นตรง Marketing Manager · B2B Executive ขึ้นตรง B2B Manager · ฝ่าย Sale ที่ถือยอดค้าปลีกไม่รวมในผังนี้

สรุป 4 ตำแหน่งในทีม

รายละเอียดหน้าที่ดูที่ JD · ตัวชี้วัดดูที่ KPI
Marketing Manager
คุมภาพรวม + ค้าปลีก/หน้าร้าน · ขึ้นตรง CMO
ทำให้ค้าส่งและค้าปลีกโตไปด้วยกัน · ดึงคนเข้าร้านและเพิ่ม conversion หน้าร้าน · คุมทีม B2B Manager + Marketing Officer (รวมงาน B2C Manager เดิมเข้ามา)
B2B Manager
คุมสายค้าส่ง · ขึ้นตรง Marketing Manager
วางแผน/คุมยอดค้าส่งทุกช่องทาง · ดีลรายใหญ่/ยกตู้ · ดูแลลูกค้าซื้อซ้ำ · คุมและพัฒนา B2B Executive
B2B Executive
ลงมือค้าส่ง + ไลฟ์ · ขึ้นตรง B2B Manager
รับลูกค้าค้าส่ง→ปิดการขาย · ดำเนินการไลฟ์ตามรอบ · ตามลูกค้าซื้อซ้ำ · บันทึกข้อมูลลูกค้าเข้าระบบ
Marketing Officer
คอนเทนต์ สื่อ ดูแลลูกค้า · ขึ้นตรง Marketing Manager
ผลิตสื่อทุกช่องทาง · คุมโทนแบรนด์ · งานจัดแสดงหน้าร้าน · ตอบลูกค้าทุกช่องทาง
