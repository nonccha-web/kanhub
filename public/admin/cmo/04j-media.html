Google Ads
งบ ~70K · เว็บ B2B
Volume-based
  • Bid ตาม volume search จริง จาก Keyword Planner — เดือนไหนคำไหนพุ่ง เทงบตาม
  • Manual CPC เก็บ baseline 2 เดือนแรก ก่อนเปิด Smart Bidding
  • Geo ภาคใต้ bid +25% — สนามที่ไม่มีคู่แข่งเล่น
  • ~10K/เดือน เฉลี่ย · เพิ่มช่วง ต.ค.–ธ.ค. ที่ผู้ค้าตุนของ
Facebook Ads
งบ ~55K · Boost Live
Promote Post
  • Boost ตัวไลฟ์ขณะออนแอร์ วันละ ~250–300฿ — ดันไลฟ์เข้า feed ผู้ค้า
  • Boost โพสต์ preview ก่อน Big Live Event (hype cycle D-3)
  • Retargeting: ผู้ชมไลฟ์ >25% + คน engage โพสต์ราคา >> ดึงเข้า LINE
  • Interest: ขายของออนไลน์ / ตลาดนัด / เสื้อผ้ามือสอง + lookalike LINE OA
TikTok Ads
งบ ~35K · Boost Live
Reach ถูก
  • Boost Live วันละ ~150–200฿ ยิงคู่กับ FB
  • หน้าที่: หาคนดูหน้าใหม่ (FB = ฐานเดิม, TikTok = ขยาย)
  • สนามขายส่ง B2B บน TikTok ยังว่าง — เจ้าใหญ่ FB ไม่ได้ย้ายมา
  • CTA เดียวกัน: รหัส + จอง >> inbox >> LINE
