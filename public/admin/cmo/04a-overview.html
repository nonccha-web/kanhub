Positioning

โกดังขายส่งเสื้อผ้ามือสองญี่ปุ่น ใหญ่ที่สุดในภาคใต้

นำเข้าตรงจากญี่ปุ่น ไม่ผ่านคนกลาง ไม่ต้องสั่งไกลถึงกรุงเทพ >> ค่าส่งถูกกว่า ของถึงเร็วกว่า และที่สำคัญที่สุดในตลาดที่มิจฉาชีพระบาด — โกดังจริง บริษัทจริง มาเปิดดูของก่อนซื้อได้ แม่ค้าไม่ต้องเสี่ยงโอนให้เพจที่ไม่เคยเห็นหน้า
🎯 Pain ที่เราแก้ (จากมุมแม่ค้า ไม่ใช่มุมเรา)
1) กลัวโดนโกง — เพจปลอมระบาดทั้งวงการ ขนาด Sabuyorder ต้องแปะ "ระวังมิจฉาชีพ" ทุกรูป 2) กลัวเปิดมาเจอขยะ — รูปสวย ของจริงเน่า 3) ต้นทุนแพง — แม่ค้าใต้ต้องสั่งจากกรุงเทพ จ่ายค่าส่งไกล รอหลายวัน 4) อยากได้แหล่งประจำ — คุณภาพนิ่ง ซื้อซ้ำได้ >> KAN ตอบครบ 4 ข้อ

คำถามที่ผู้ค้าจะถามแน่นอน — เตรียมคำตอบไว้ล่วงหน้า (ใช้ใน FAQ + ไลฟ์)

คำถามที่ผู้ค้าจะถามคำตอบของ KAN
"KAN ขายปลีกแข่งกับร้านเราหรือเปล่า"ตอบตรง ไม่หลบ: ตลาดมือสองภาคใต้ใหญ่กว่าที่คิด — หน้าร้าน KAN ขายในห้องแอร์ ราคา retail / ตลาดนัดขายอีกราคา อีกทำเล อีกกลุ่มลูกค้า ผู้ค้ามือสองภาคใต้หลักพันรายแข่งกันเองอยู่แล้วและอยู่ได้ สิ่งที่ทำให้ผู้ค้าเจ็บจริงคือต้นทุนแพงเพราะสั่งไกล + โดนเพจปลอมโกง ซึ่งคือ 2 อย่างที่เราแก้ให้
"เอาของเหลือจากหน้าร้านมาขายหรือเปล่า"คนละ lot — กระสอบขายส่งอัดมาจากญี่ปุ่น ยังไม่เคยเปิด นำเข้ามาเพื่อขายส่งโดยเฉพาะ มาเปิดดูที่โกดังได้ว่าตะเข็บกระสอบเดิม
"ทำไมต้องซื้อกับ KAN"ใกล้กว่า (ค่าส่งถูก/มารับเองได้) + เห็นของจริงก่อนโอน + บริษัทจริง หน้าร้าน 4 สาขา ตรวจสอบได้

Core Strategy — 3 Phase

  • Test (มิ.ย.–ส.ค.): เว็บ live สิ้น มิ.ย. · เริ่มขายจริง ก.ค. · Live Pilot 3 events · เก็บตัวเลขทุก channel
  • Review (ก.ย.): เทียบยอด/ต้นทุนต่อ channel · ตัดสินใจ weight งบ Q4
  • Scale (ต.ค.–ธ.ค.): เทงบใส่ channel ที่ชนะ · อิงพีคปลายปี (ลอยกระทง · Black Friday · ปีใหม่)

จุดแข็งที่คู่แข่งไม่มี

  • ทำเลใต้: โกดังขายส่งใหญ่ทุกเจ้าอยู่ กทม./สมุทรสาคร/นครปฐม
  • นำเข้าตรงญี่ปุ่น: volume เดียวกับ retail 4 สาขา = ต้นทุนต่ำ
  • โกดัง+หน้าร้านจริง: trust ที่เพจปลอมเลียนแบบไม่ได้
  • รู้ตลาดจริง: ใช้ใน segment "สอนแม่ค้า" ในไลฟ์ — ไม่ใช้โฆษณาตรงๆ
