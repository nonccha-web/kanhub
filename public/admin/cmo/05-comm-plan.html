ทำไมต้องไปด้วยกัน

กลยุทธ์หลัก — ทำไมต้องลดจำนวนโปร

โปรเดิม 10–20 ตัวต่อเดือน แต่ลูกค้าใช้จริงแค่ 20% ที่เหลือคือเสียงรบกวนที่กินพื้นที่สื่อสารฟรีๆ แผนนี้รวมพลังไปที่โปรน้อยตัวแต่สื่อสารหนัก

Gold Promo ไม่เกิน 3 ตัว/เดือนเวียนทุกเดือน ทุ่มพลังสื่อสารไปที่โปรน้อยตัว แทนการกระจาย 20 โปร
เทงบไปทำสื่องบที่ประหยัดจากการลดโปร เปลี่ยนเป็น reach + ป้าย ไม่ใช่ส่วนลด
เห็นเกิน 7 ครั้งกฎทอง — คนต้องเห็นข้อความเดียวกันเกิน 7 ครั้งข้ามทุกช่องทาง ก่อนตัดสินใจ
เป้าหมายปลายทาง: frequency 7+ ไม่ใช่เป้าในตัวเอง — มันคือเครื่องมือเพื่อ ดัน traffic เข้าร้านเพิ่มขึ้นตาม KPI วัดผลด้วย PeopleFlow (นับคนหน้าร้าน) เชื่อมกลับ bottleneck เดิม revenue per sqm
📸

ธีมภาพหลักทุกสาขา: ภาพถ่ายจริง ไม่ตกแต่งเยอะ — ตรงกับจุดยืน "ของจริง บริษัทจริง" และถ่ายเองได้ ไม่ต้องพึ่ง production แพง สอดคล้องนโยบายเทงบไป reach

ครั้ง 1–3
รู้จักEducation + Add Value — "ร้านนี้รู้จริงเรื่องมือสองญี่ปุ่น"
ครั้ง 4–5

ปิดท้าย
Traffic เข้าร้าน (KPI)ป้ายหน้าร้านเปลี่ยน "เดินผ่าน" เป็น "เดินเข้า" · วัดด้วย PeopleFlow

หลักการปฏิทิน · Gold Promo ไม่เกิน 3 ตัว/เดือน

เดือนหนึ่งปล่อย Gold Promo ได้ไม่เกิน 3 ตัว เวียนหมุน — ไม่กำหนดวันปล่อยตายตัว เลือกจังหวะตามสต๊อก/เทศกาล/พฤติกรรมลูกค้าแต่ละเดือน แต่ละตัวมีโครงเดียวกัน

ระหว่างรอบ — สะสมความรู้จัก

Education + Add Value + Brand เดินสม่ำเสมอตลอดเดือน สร้างการเห็นแบบ "รู้จัก + เชื่อ" (บันไดครั้ง 1–5)

ช่วงปล่อย Gold Promo — เร่งให้เข้าร้าน

แต่ละ Gold Promo มี hype cycle ของตัวเอง (teaser → เตือน → วันปล่อย → ตามต่อ) + งานเคลียร์ ดันให้ "ต้องไปวันนี้" (บันไดครั้ง 6–7)

งานเคลียร์วางให้ตรงจังหวะหมุนสต๊อก · Gold Promo ทั้ง 3 ตัวไม่ปล่อยติดกัน เว้นช่วงให้ Always-on content สะสม frequency · ปฏิทินนี้เป็น template กลาง ทุกสาขาใช้จังหวะ+น้ำเสียงเดียวกัน แต่ "ของจริงในโพสต์" ปรับตามสต๊อกแต่ละสาขา

เพจ vs Facebook Group — คนละ logic

เพจ

สร้างรู้จัก + เชื่อ → ดัน traffic
  • คอนเทนต์ครบ 4 tier ตามสัดส่วน
  • ภาพถ่ายจริงเล่าเรื่อง
  • คนแปลกหน้าเลื่อนเจอ → ต้องสะกดด้วย value

Facebook Group

ลงของล้วน → ปิดการขาย
  • ภาพจริง + ราคา + รหัส ครบในโพสต์เดียว
  • ลงเป็นรอบเช้า/เย็น สร้าง habit
  • tag 3 ขั้นในโพสต์ เร่งตัดสินใจ
  • คอมเมนต์รหัส → ทัก LINE ปิดดีล
  • ทุกดีลมี "มารับที่ร้านได้" → traffic หน้าร้าน
⚠️

ข้อควรระวัง workload: เพจ + Group ใช้ทีมคอนเทนต์ทีมเดียวกัน การลงของรอบเช้า/เย็นทุกวันหลายสาขาเป็นภาระหนัก — แนะนำใช้ KAN Scout (ถ่ายรูป → ได้ caption/ราคาอัตโนมัติ) ช่วยลดเวลาตรงนี้
